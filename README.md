# CCST-IT-Support-Home-Lab

Hands-on IT Support labs covering Windows, networking, DNS, troubleshooting, and security.

## Labs

### 01 - DNS Troubleshooting

Hands-on DNS troubleshooting using Windows networking tools, including `ipconfig`, `ping`, and `nslookup`.

### 02 - Windows Troubleshooting

Practical Windows troubleshooting using built-in system and support tools.

### 03 - Network Troubleshooting

Hands-on investigation of common network connectivity problems.

### 04 - Printer Troubleshooting

Practical troubleshooting of Windows printing and print queue issues.

### 05 - Security Troubleshooting

Basic endpoint security investigation and incident response exercises.

### 06 - Real-World Website Support

A documented real-world website support task covering issue investigation, troubleshooting, change implementation, testing, and resolution verification, including AI-assisted troubleshooting with CludAI.

### 07 - Windows Troubleshooting

Practical Windows troubleshooting using built-in system and support tools.
